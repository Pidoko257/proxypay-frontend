# Initiate Payment

**POST** `/v1/payments`

Initiates a Mobile Money payment. On success, a `transaction_id` is returned that can be used with the [Transaction Status](/transaction-status) page to track progress.

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `amount` | number | Yes | Payment amount in the specified currency |
| `currency` | string | Yes | ISO 4217 currency code (e.g. `USD`, `TZS`) |
| `phone` | string | Yes | Recipient phone number in E.164 format |
| `description` | string | No | Human-readable payment memo |

```bash
curl -X POST https://api.proxypay.io/v1/payments \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \

    "currency": "USD",
```

```python
import os
import requests

response = requests.post(
    'https://api.proxypay.io/v1/payments',
    headers={
        'Authorization': f'Bearer {os.environ["PROXYPAY_API_KEY"]}',
        'Content-Type': 'application/json',
    },
    json={
        'amount': 10.00,
        'currency': 'USD',
        'phone': '+255712345678',
        'description': 'Order #1042',
    },
)

data = response.json()
print(data['transaction_id'])
```

```php
<?php

$payload = json_encode([
    'amount'      => 10.00,
    'currency'    => 'USD',
    'phone'       => '+255712345678',
    'description' => 'Order #1042',
]);

$ch = curl_init('https://api.proxypay.io/v1/payments');
curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => $payload,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => [
        'Authorization: Bearer ' . getenv('PROXYPAY_API_KEY'),
        'Content-Type: application/json',
    ],
]);

$response = json_decode(curl_exec($ch), true);
curl_close($ch);

echo $response['transaction_id'];
```

## Response

```json
{
  "transaction_id": "txn_abc123",
  "status": "Initiated",
  "created_at": "2026-06-28T12:00:00Z"
}
```

## Error codes

| Code | Meaning |
|---|---|
| `INVALID_PHONE` | Phone number is not in E.164 format |
| `INSUFFICIENT_FUNDS` | Sender account balance too low |
| `UNSUPPORTED_CURRENCY` | Currency is not enabled for this account |
