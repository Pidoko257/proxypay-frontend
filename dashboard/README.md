# Dashboard

The dashboard is the API portal home page. It introduces the API and guides a new
integration developer from setup to a first successful request.

## Getting started

Follow this path in order to go from zero to your first successful API call.

1. **Prerequisites** — confirm you have an account and the tooling you need before
   you start: [Prerequisites](/docs/getting-started/prerequisites).
2. **Authentication** — create and use your API credentials:
   [Authentication](/docs/getting-started/authentication).
3. **First API call** — make your first request against the published base URL:
   [First API call](/docs/getting-started/first-api-call).
4. **Workbench** — explore and try requests interactively:
   [Workbench](/docs/workbench).

Each link is relative to the published base URL, so the path resolves correctly in
any deployment environment.
